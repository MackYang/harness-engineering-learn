### 重新确认的核心要点

连续五周（07-27、08-03、08-10、08-17、09-14）审视确认文章无变化。核心要点保持稳定：

1. AGENTS.md 作为目录（~100行）而非百科全书，docs/ 结构化知识库为 system of record
2. "人类不写代码"零手动代码原则（1500 PR，~100万行代码，3→7人团队，吞吐反升）
3. 架构约束优先于实现细节（Types → Config → Repo → Service → Runtime → UI 固定层级 + Providers 单一入口）
4. 垃圾回收式技术债务管理（黄金原则 + 定期后台 Codex 扫描 + 自动合并重构 PR）
5. 端到端自主性里程碑（单 prompt 驱动完整功能：复现→录屏→修复→验证→PR→合并）
6. 应用可读性提升（per-worktree 可启动实例 + CDP + LogQL/PromQL 可观测性栈）
7. Agent 可读性作为目标（仓库内版本化制品是代理唯一可见信息；"无聊技术"更易被代理建模）
8. 通过量改变合并哲学（最小阻塞门控，短命 PR，修正比等待便宜）
